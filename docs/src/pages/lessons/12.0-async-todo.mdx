第 11 章把任务存进了当前浏览器。想在另一台设备上看到同一份待办，就得把它们存到服务器。打开应用时要等服务器把任务送过来，修改任务后也要等服务器确认保存。

等下面的 Todo 读完任务，勾选“订会议室”，等顶部变成“全部已同步”。再新增一项。它会立刻出现在列表里，旁边标着“待同步”。趁这个提示还在，点“重新打开应用”。等两秒读回列表，会议室的勾还在，刚新增的任务没有保留。

<AsyncTodoDemo client:load />

演示里的模拟服务器在保存计时结束时写入数据并确认。重新打开会取消还没确认的模拟保存，再从服务器读回最后确认的列表。真实的 HTTP 请求可能已经写入服务器，客户端却没能收到响应。

同一项任务也可以连续改两次。第一次保存结束时，页面上可能已经是第二次修改后的样子，这一行仍要标“待同步”。接下来我们先处理迟到的读取结果，再让 Store 按顺序保存，避免旧快照覆盖较新的修改。

- 12.1 让异步资源只提交最新结果。用一个 signal 表示请求状态，处理取消、乱序与卸载。
- 12.2 异步 Todo Store 与串行保存。接上可控的内存仓库，分开处理加载、界面修改和保存。
- 12.3 用 HTTP 仓库接入 Todo 后端。沿用同一个 Store，把读写换成真正的网络请求。
- 12.4 用任务调度器延后统计。给任务分优先级，合并重复的待执行任务，在卸载时取消它们。
