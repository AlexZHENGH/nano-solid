在 `runEffect(effect)` 的 `try` 和 `finally` 之间补上 `catch (error)`，直接复用 [3.3](../3.3-dispose/) 的 `disposeEffect(effect)` 清理半截订阅，再把原异常继续向外抛出：

```ts
function runEffect(effect: Effect): void {
  // 同一轮通知快照里，前面的 effect 可能已经释放了当前节点，进入前必须先跳过。
  if (effect.disposed) return;
  cleanupDependencies(effect);
  // 保存外层 effect，并在 try/finally 中恢复；若回调抛错，则在 catch 中释放半截订阅后继续抛出。
  const previous = currentEffect;
  currentEffect = effect;
  try {
    effect.callback();
  } catch (error) {
    disposeEffect(effect);
    throw error;
  } finally {
    currentEffect = previous;
  }
}
```

无论是首次执行还是后续重跑，只要回调在读完部分 signal 后抛错，都会立刻断开这些半截订阅并把 `disposed` 置为 `true`，同时原样抛出错误且在 `finally` 里恢复外层 `currentEffect`。
